# Figma 設計稿版本紀錄

設計師會把定稿複製成新檔案，所以每一版的連結都不一樣。流程見 `/figma-page` skill。

- `snapshots/`：每個 frame 一份最新快照（由 `snapshot.mjs` 產生），舊版本在 git 歷史裡。
- 比對：覆寫快照後執行 `git status --porcelain figma/snapshots/`，`M` 是修改，`??` 是新增，`D` 是刪除。
